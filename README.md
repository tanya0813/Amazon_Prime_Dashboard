Hello! I have made an interactive Amazon_Prime  Dashboard on power BI!


This project is a Power BI dashboard that explores and visualizes data from Amazon Prime Video, including insights on:

Title distribution by country, genre, rating, and type

Trends in movie and TV show releases

Total counts of shows, genres, directors, and more


**Key Metrics**
Metric	        Value
Total Titles	  9,655
Total Ratings	     25
Total Genres	    519
Total Directors	 5,771
Earliest Release	1920
Latest Release	  2021

**Dashboard Insights**
Top Genres: Drama, Comedy, and Suspense dominate.

Rating Breakdown: Most shows are rated 13+ or 16+.

Movies vs TV Shows: ~81% are movies, ~19% are TV shows.

Country-wise Distribution: Global content with strong contributions from North America and Europe.

Time Trends: Content production surged after 2000.
